# Using LaoPhon

## English

1. Download the ZIP for your operating system from the [latest release](https://github.com/WanglwDev/LaoPhon/releases/latest).
2. Extract it completely. On Windows, open `LaoPhon.exe` inside the extracted folder and keep all adjacent files. On macOS, open `LaoPhon.app`.
3. Select **中文** or **English** in the upper-right header. Your preference is saved locally.
4. Enter Lao text and select **Segment syllables**. Check the proposed boundaries and edit them with spaces. Correct red segments before transcription and review yellow notices.
5. Select **Confirm and generate IPA**, optionally add spaces between syllables, and select **Copy output**.
6. Open **Tone profiles** to edit Vientiane (万象) or add a new variety. Tone categories, initial consonant letters, vowel letters, and final letters remain editable. Saving and using a profile are separate operations.
7. Expand **Saved segmentation corrections** to save confirmed boundaries or export/import a correction backup.

Text, profiles, corrections, and interface preferences remain on the local computer. No account or network connection is required for the packaged application. Profiles are not automatically synchronized between computers. This distribution starts with Vientiane only and includes no personal profiles or correction records.

System requirements: Windows 10 / 11 x64, or macOS 13+ with the matching Apple silicon/Intel download. The Mac application is ad-hoc signed and not notarized; the Windows application is not commercially code-signed. Check `SHA256SUMS.txt` against downloaded files when needed.

Segmentation and IPA follow the current spelling and conversion rules. Ambiguities, unusual spellings, and pronunciation still require human review.

## 中文

1. 从 [最新发布页](https://github.com/WanglwDev/LaoPhon/releases/latest) 下载对应系统的 ZIP。
2. 完整解压。Windows 在解压文件夹内打开 `LaoPhon.exe`，保留旁边的全部文件；Mac 打开 `LaoPhon.app`。
3. 在页首右侧选择 **中文** 或 **English**，软件会在本机保存选择。
4. 输入老挝文，点击 **自动拆分音节**，人工核对并用空格调整边界；先修正红色片段，核对黄色提示。
5. 点击 **确认并生成 IPA**，可选择音节间加空格，再点击 **复制结果**。
6. 打开 **声调方案** 编辑万象或新增语言点。调类、起始辅音字母、元音字母和尾音字母均可编辑；“保存”和“保存并使用”是不同操作。
7. 展开 **本机拆分校正** 保存确认过的边界，或导出、导入校正备份。

文本、方案、校正与界面偏好均保存在本机。使用打包后的软件无需账号或联网，电脑间不会自动同步方案。初始仅预置万象，不包含个人语言点或校正记录。

系统要求：Windows 10 / 11 x64；或 macOS 13 及更新版本，并下载对应 Apple 芯片 / Intel 包。Mac 仅做 ad-hoc 签名，未经公证；Windows 未做商业代码签名。需要时可使用 `SHA256SUMS.txt` 核对下载文件。

拆分和 IPA 遵循现有拼写与转换规则；歧义、特殊拼写及实际读音仍需人工核验。
